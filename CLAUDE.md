# Breakup (nicotine_web_app) — правила проекта

Продукт помогает бросить никотин (сигареты, вейп, пакетики) через метафору расставания с токсичным бывшим по имени Ник. 18+.

## Порядок работы: сначала сайт, потом приложение

1. **Фаза 1 — сайт и веб-приложение.** Лендинг плюс сам продукт в браузере: онбординг-опрос, оплата, чат с Ником, «Волна», мозг по неделям, копилка. Должно работать на телефоне как приложение (PWA).
   - Стек по умолчанию: Next.js (App Router), React, TypeScript, Tailwind CSS v4, компоненты coss ui (Base UI), анимации — Motion (`motion/react`) и CSS.
   - Оплата в вебе — Stripe или RevenueCat Web Billing; решаем перед экраном оплаты.
   - Данные пользователя — по возможности только на устройстве.
2. **Фаза 2 — приложение на Expo.** Не начинать, пока сайт не проверен на живых пользователях. Скиллы для неё лежат в `docs/app-phase/skills/` и переезжают в `.claude/skills/` в начале фазы.

Если задача неоднозначна — решаем её для сайта.

## Когда скиллы спорят — что побеждает

Источники противоречат друг другу. Решение принято здесь, а не в каждом разговоре заново. Порядок: слова владельца → этот файл → скилл.

1. **Анимация.** Правила Эмиля Ковальски сильнее «живого» стиля taste-skill и `baseline-ui`:
   - интерфейсная анимация короче 300 мс, выход быстрее входа;
   - по умолчанию ease-out, никогда ease-in; не анимировать от `scale(0)`;
   - не анимировать действия, которые человек делает десятки раз в день (переключение вкладок, отправка ответа);
   - пружина — только когда движение ведёт палец или курсор;
   - никаких вечных микро-петель на компонентах. Единственная долгая петля — «Волна», это сам продукт;
   - `prefers-reduced-motion` уважается везде.
2. **Эмодзи разрешены** в репликах Ника и в чате: это переписка, а не интерфейс. В кнопках, заголовках и навигации — нет. Запрет эмодзи в taste-skill здесь не действует.
3. **Компоненты — одна система.** Основа — coss ui (Base UI). Правила shadcn/Radix из `ui-styling` применяются только там, где не противоречат coss. Компоненты sl-ui-library не используем (ванильный HTML).
4. **Тосты.** Подтверждения и ошибки внутри продукта по возможности говорит Ник, в чате, своим голосом. Тост — только для системных вещей вне сюжета (сеть пропала, оплата прошла).
5. **Диегетичность.** Двигается то, что «живёт» в мире продукта: волна тяги, мозг, копилка, печатающий Ник. Карточки и кнопки не пульсируют просто так.
6. **Длинное тире.** Запрет тире из taste-skill в русском тексте не действует: «Пачка в день — это…» требует тире по правилам пунктуации. Запрет остаётся для декоративных разделителей.
7. **Вибрация и звук** — на события (сообщение Ника, пройденная волна, веха), не на каждое нажатие.

## Цвет — по данным, а не на вкус

Обоснование и источники — `docs/research/color-evidence.md`. Роли закреплены, новые цвета не вводить без новых данных:

| Роль | Светлая тема (день) | Тёмная тема (вечер) | Почему |
|---|---|---|---|
| Фон | `#F3F6F6` | `#121819` | Днём тёмный текст на светлом читается лучше (Piepenbrock 2013); ночью важна общая яркость экрана (Nagare 2018) |
| Текст | `#132125` | `#E2EBEB` | Контраст 15:1 |
| Ник | `#4A412A` (семейство Pantone 448C), текст на нём `#EEE9DA` | то же | Самое нелюбимое семейство оттенков (Palmer & Schloss 2010). Только реплики и знак, никогда не поле |
| Человек, прогресс, действие | `#0E7480`, пузырь `#CDEEEF` | `#6CC9D1`, пузырь `#1C4A50` | Самое любимое семейство. От Ника отличается и оттенком, и светлотой, поэтому различим при дальтонизме |
| Награда | `#F0B23F` | `#D9A23E` | Только в момент реального события, иначе связь «цвет = достижение» размывается (Anderson 2011) |
| Опасность | красный средней насыщенности | — | Всегда с иконкой и текстом (WCAG 1.4.1) |

- Возбуждение и приятность управляются насыщенностью и светлотой, а не оттенком. Приятнее всего яркие насыщенные цвета (Valdez 1994, Wilms 2018), поэтому витрина и главный экран — яркие: насыщенное небо `#1E9BEA` → `#4EC0F4` → `#BFEAFB`, ночью `#081A3D` → `#2A64A8`, текст на небе `#06243F`. Низкая насыщенность — только на экранах тяги («Волна», ночной SOS).
- Главный экран (v4, «Ник затянул тебе небо»): облако цвета 448C висит только вокруг сообщений Ника и рассеивается после «Расстаться»; солнце `#FFC94D` выходит как награда. Первый кадр всегда яркий.
- Рамки элементов управления — не меньше 3:1 к фону (`--control`), текст — не меньше 4.5:1.
- Не показывать реалистичные сигареты, вейпы, пачки и дым: такие изображения сами вызывают тягу (Engelmann 2012, Vinci 2020). Ник — персонаж, а не предмет.
- В маркетинге не утверждать, что цвета снижают тягу, «успокаивают» или «дают дофамин» — данных нет (список в конце исследования).

## Против «ИИ-дизайна»

Первый прототип местами выглядел сгенерированным. Полный аудит по всем скиллам — `docs/research/v2-skills-audit.md`. Не повторять:
- телефон, нарисованный блоками, вместо настоящего работающего компонента;
- раскладку, которая прыгает после нажатия;
- одинаковые карточки со скруглением и рамкой на каждом блоке — отделять только то, что действительно отдельный объект;
- надписи капсом над каждой секцией;
- градиенты ради градиентов, неон, стеклянные панели;
- центровка всего подряд;
- шрифты по умолчанию. Шрифт выбирается под характер продукта и обязан поддерживать кириллицу.

Перед сдачей экрана: `break-ui`, `web-design-guidelines`, чек-лист ui-ux-pro-max, скриншот реального рендера на ширине телефона и десктопа (`webapp-testing`).

## Честность — не обсуждается

- Никаких фальшивых таймеров, выдуманных отзывов, давления виной при отмене подписки.
- «Помогает бросить», а не «лечит». Научные утверждения — только с источником (Cosgrove 2009, ВОЗ, Cochrane и т. д.).
- Напоминание за 2 дня до списания и отмена в одно нажатие.

## Безопасность сторонних скиллов

Каждый скилл прочитан целиком до установки. Не устанавливались и не возвращаются без отдельного решения владельца:
- скиллы, которые грузят инструкции из сети без закреплённой версии (`ui-skills` CLI, исходный `web-design-guidelines` — его правила вшиты локально в `command.md`);
- `deploy-to-vercel` (отправляет архив проекта на сторонний адрес), `vercel-cli-with-tokens` (печатает токен в лог);
- соседние скиллы ui-ux-pro-max с генерацией картинок через платные API и чтением глобальных `.env`;
- папка `stack/` из ui-ux-pro-max (открывает чтение всего `/home`).

Новый скилл — тоже сначала читать целиком.
