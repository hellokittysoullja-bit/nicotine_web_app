# Аудит v5 «Живое небо» по всем скиллам

Дата: 12.10.2026. Файл: `design/directions/v5-sky-live.html` (434 строки). Файл не правился.

Метод:
- Прочитаны целиком: taste-skill (раздел 14 построчно, плюс 6, 8, 9), frontend-design, redesign-skill, emil-design-eng, apple-design, vercel-web-design-guidelines (`command.md`), fixing-accessibility, fixing-metadata, mobile-native, break-ui, review-animations вместе со STANDARDS.md, animation-performance, fixing-motion-performance, motion-design (`duration.md`, `easing.md`, `accessibility.md`), ui-ux-pro-max (`--domain ux`: touch target, focus, slider, radio, hover, loading, reduced motion, gesture swipe, keyboard navigation, contrast).
- Свой прогон Playwright (Chromium) на ширинах 1440×900, 390×844, 320×568 и 720×450 при DPR 2 (это зум 200% для экрана 1440). Обе темы, `reducedMotion: 'reduce'`, `hasTouch` + `isMobile`.
- Касания — через CDP `Input.dispatchTouchEvent`: горизонтальные и вертикальные свайпы, смена размера окна.
- Скорость: rAF-интервалы и `Performance.getMetrics`, в том числе при замедлении процессора в 4 раза.
- Контраст считался по формуле WCAG 2.x по реальным пикселям. Текст прятался (`color: transparent`), делался снимок фона в 4 момента дрейфа облака (3.5, 7, 12 и 20 с), полупрозрачный текст смешивался с каждым пикселем фона. В таблице 2-й перцентиль по пикселям, то есть худший участок под строкой.

CLAUDE.md побеждает скилл там, где они спорят. Такие места помечены «CLAUDE.md».

Обозначения: **FAIL** — нарушение, pass — правило выполнено, n/a — правило к странице не относится.

| Сценарий | Результат |

### 0.6 Производительность цикла облака

| Режим | Медиана кадра | p95 | Скрипт за 3 с | Загрузка основного потока |
|---|---|---|---|---|
| 1440, без замедления | 16.7 мс | 16.8 | 0.24 с | ≈8% |
| 390 DPR3, без замедления | 16.7 | 16.8 | 0.76 с | ≈25% |
| 390 DPR3, CPU ×4 (аналог среднего телефона) | 16.8 | **33.4** | **2.25 с** | **≈99%** (Task 2.98 с из 3) |
| hero ушёл из вида (scrollY 3000) | — | — | **то же самое: 0.24 / 0.75 / 2.20 с** | цикл не останавливается |
| `prefers-reduced-motion` | — | — | 0.23 с | **цикл крутится 60 раз в секунду, рисуя неподвижную картинку** (`ratio` не меняется) |
| 3 события `visibilitychange` | — | — | — | **`putImageData` 60 → 240 раз в секунду**: каждое возвращение на вкладку добавляет ещё одну цепочку rAF (стр. 380) |

Почему на телефоне дороже:
- на десктопе сетка шума 128×80;
- на мобильном hero высокий и узкий: `GH = 128·h/w ≈ 277`, всего 35 тыс. ячеек;
- на каждую ячейку три вызова `vnoise`, плюс `clear.reduce` по всему массиву и `getBoundingClientRect` четыре раза за кадр.

## 12. review-animations

### Часть 1 — находки

| Before | After | Why |

| `.note.gone` всегда влево | по направлению свайпа | пространственная согласованность |
| `cardin` 340 мс keyframe (113) | 240 мс | UI ≤300 мс |
| `.dot` `border-width` (120) | `::after` `scale(.4→1)` | GPU-свойства |
| reduced motion: цикл rAF (379) | рисовать по событию | доступность и батарея |
| Реплики приходят через 450 + i·650 мс (269) | оставить | это переписка, ритм сообщений, а не UI-стаггер; правило 30–80 мс к нему не относится |
| Подсказка через 2600 мс (270) | 1500 мс после третьей реплики (то есть 1750) или сразу на `pointer: coarse` | на телефоне человек начинает листать раньше |

### Часть 2 — вердикт

1. **Feel-breaking:** мышь без нажатия стирает реплики; реплики мигают на пороге без гистерезиса; облако исчезает растворением, а не уносится жестом.
2. **Упростить:** блюр-стекло карточки.
3. **Производительность:** бесконечный цикл вне экрана и при reduced motion, двойной цикл после `visibilitychange`, 99% основного потока на среднем телефоне.
4. **Тайминг:** выходы равны входам.
5. **Origin:** реплики уходят не туда, куда их смахнули.
6. **Доступность:** reduced motion в JS не учтён.

**Решение: Block.**

## 18. Что нужно проверить на настоящем телефоне

| Находка | Почему эмуляция не отвечает |
|---|---|
| Горизонтальный свайп от левого края на iOS (жест «назад») и на Android с жестовой навигацией | системные жесты в Chromium-эмуляции не воспроизводятся |
| Как часто iOS Safari шлёт `resize` при сворачивании панели адреса — и, значит, как часто обнуляется облако (§0.5) | в эмуляции панели нет |
| `ctx.filter = 'blur()'` в Safari 16–17 | Chromium поддерживает, Safari — не во всех версиях; без него облако клетчатое |
| Реальная цена кадра и нагрев | CPU ×4 моделирует процессор, а не GPU и память |
| `100svh`, чёлка, Dynamic Island, `env(safe-area-inset-*)` | только железо |
| Чувство свайпа: сила, задержка, «уносится ли» облако | ощущение, а не число |
| Вибрация на Android при финале | iOS её не поддерживает |
| Прокрутка, начатая на облаке: не теряется ли инерция | `touch-action: pan-y` в эмуляции работает, на iOS 15–16 бывали различия |
