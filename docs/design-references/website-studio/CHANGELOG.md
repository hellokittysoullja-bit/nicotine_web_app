# Changelog

All notable changes to Website Studio are documented here.

## 1.0.0 - 2026-07-12

Initial public release.

- Added the seven-gate website workflow from brief through hosting handoff.
- Added eight website recipes and four optional capability recipes.
- Added Sites, existing-project, static, and generic-framework adapters.
- Added templates for briefs, capability, routes, flows, permissions, sources, and media.
- Added six deterministic validators with Node.js 20+ and seven automated tests.
- Added three original, responsive HTML examples.
- Added cross-Agent installation guidance for Codex, Claude Code, Gemini CLI, GitHub Copilot, Cursor, Windsurf, OpenCode, Cline, and Roo Code.
