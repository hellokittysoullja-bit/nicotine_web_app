# Design Quality

Good website design makes the user's next decision easier while giving the subject a recognizable visual voice. It is not the accumulation of fashionable effects.

## Establish an Art Direction

Write one sentence that connects tone, subject, audience, and intended feeling. Extract three to five visual cues from the product, organization, place, material, era, or user task. Translate each cue into a concrete decision.

The site should remain recognizable after removing its logo. If it becomes interchangeable with unrelated products, the direction is not specific enough.

## Define the System Before Components

- **Color:** use a small structural palette and reserve strong color for priority, state, or identity. Confirm text contrast in every state.
- **Typography:** assign clear roles to display, reading, interface, and data text. Control line length, line height, and fluid headline scale.
- **Spacing:** establish a repeatable rhythm while allowing larger narrative pauses where appropriate.
- **Geometry:** choose corner treatment, border weight, shadows, and container behavior deliberately. Do not mix unrelated component languages.
- **Grid:** use alignment to create trust, then introduce asymmetry only where it strengthens hierarchy.
- **Motion:** animate feedback and state change. Avoid motion that delays reading, causes layout shift, or communicates essential information alone.

Avoid default purple gradients, universal glass panels, oversized pills, identical rounded cards, random icon collections, and decorative dashboards. Any of these can be valid when the brief supports them; none is a substitute for direction.

## Design the First Viewport

The first viewport should communicate:

- what this site is;
- who it is for;
- why it matters;
- what the visitor should do next.

Do not spend the first screen on generic navigation chrome, unexplained animation, or an image that competes with the value proposition.

## Use Imagery Purposefully

Classify imagery as product evidence, work sample, portrait, key composition, atmosphere, diagram, or decoration.

- Preserve complete group, poster, document, and product compositions when cropping would remove meaning.
- Use intentional focal positions for photography at each responsive size.
- Do not use unrelated stock imagery to fill visual space.
- Prefer real product or subject evidence over invented interface mockups.
- Treat generated imagery as original creative material that still requires review for text errors, artifacts, and misleading detail.
- Keep attribution and license obligations attached to the asset.

## Compose Responsive Transformations

Do not scale a desktop screenshot down. Decide how each region transforms:

- multi-column grids reduce in meaningful reading order;
- dense navigation becomes an explicit, keyboard-safe menu;
- secondary panels move below primary content;
- tables gain an appropriate narrow-screen strategy;
- headlines use fluid bounds and remain intact at minimum width;
- touch targets gain space without hiding important content.

Support narrow screens without using hidden overflow to conceal layout errors.

## Design Every State

Components are incomplete until their relevant states are designed: default, hover, focus, active, selected, disabled, loading, empty, error, success, and permission-limited.

Not every component needs every state. Every state the product can actually enter needs a clear visual and textual treatment.

## Accessibility Is Visual Quality

- Use logical heading hierarchy and landmarks.
- Keep focus visible and reading order consistent with layout order.
- Give controls descriptive names and expose expanded, selected, or pressed state.
- Maintain contrast without relying on color alone.
- Provide meaningful alternative text and titled embeds.
- Respect reduced-motion preferences and text zoom.
- Ensure pointer, keyboard, and touch users can complete the same tasks.

## Quality Review

- [ ] The visual direction is specific to the subject and user job.
- [ ] Priority is obvious within a short first-screen scan.
- [ ] The system is consistent without making every section identical.
- [ ] Imagery functions as evidence or atmosphere with deliberate crops.
- [ ] Wide, medium, and narrow layouts feel composed independently.
- [ ] Real interaction states are visible, readable, and accessible.
- [ ] No starter content, arbitrary decoration, or accidental style mixture remains.
